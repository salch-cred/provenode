# Model Provenance

One of Provenode's most powerful features is the **Model Provenance Chain**.

When you register a model on Provenode, it isn't just saved in a database; it is cryptographically signed and its hash is anchored to the decentralized **Shelby Protocol**.

## Cryptographic Certificates

For every deployed model, Provenode generates an on-chain provenance certificate. This certificate guarantees:
* The exact time the model was registered.
* The exact cryptographic hash (SHA-256) of the model weights.
* The identity of the deployer.

## QR Verification

On the Provenode **Registry** page, every model features a QR code. Scanning this QR code directs you to a public verification portal. This allows external auditors, users, and regulatory bodies to instantly verify that the model they are interacting with is the authentic, unaltered version registered by your organization.
