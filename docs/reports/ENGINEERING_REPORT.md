## Security remediation (2026-08)

A full audit of `api/index.js` (3.3k lines) and `lib/` found and fixed:

**Critical**
- `requireAuth` / `isAdminRequest` failed **open** when `DEPLOY_SECRET` was
  unset — and `.env.example` shipped it empty, so a by-the-book deploy ran a
  fully anonymous API. Now fails closed (503) in any production runtime;
  `ALLOW_OPEN_API=true` restores open mode for local development only.
  Token comparison uses `timingSafeEqual`.
- Tenant isolation was bypassable: `X-Tenant-Id: admin-override` (or `global`)
  collapsed to the shared namespace, and Redis glob metacharacters in a tenant
  id widened `SCAN MATCH`. Both sanitized in `lib/kv.js`; `list()` caps at
  5 000 keys.
- Audit log, payments, and webhook dispatch read the **global** namespace while
  writes were tenant-scoped, so an unauthenticated `GET /api/audit` dumped every
  tenant's history, `/api/earnings` exposed all settlements, and
  console-registered webhooks never fired at all. All three tenant-scoped.
- Stored XSS: uploaded site HTML/SVG was served from the console origin with no
  CSP, and the deploy token lives in `localStorage`. Site content now ships a
  sandbox CSP (`script-src 'none'`) plus `X-Content-Type-Options: nosniff`.
- `PrivyGuard` — the only writer of `localStorage.tenant` — was never mounted,
  so all users shared one namespace regardless of login. Folded into
  `AuthGuard`.

**High**
- Paywall: a paid `anon` intent unlocked a blob for everyone permanently.
  Replays now require the same micropayment proof that settled the intent.
- Payment intents were bound to neither item type nor amount and were never
  consumed, so a `download` intent (0.0001 ShelbyUSD) could import any priced
  marketplace listing, repeatedly.
- The "ZK proof" generated a throwaway keypair inside the prover and embedded
  the matching public key, so every proof verified and none proved anything.
  Rewritten as an org-key-signed execution attestation verified against the
  identity key. Renamed honestly — it is an attestation, not a zk-SNARK.
- ZIP handling enforced size caps *after* decompressing every entry (~2 GB from
  a 50 MB archive). Caps now apply inside the loop using the header size.
- Unknown `/s/<slug>` dereferenced a null site → 500 on every bad public URL.
  Returns 404. Public serving resolves through a global slug index, so
  tenant-owned sites are reachable and slugs are globally unique.
- `STANDARD_BENCHMARK_VECTORS` was referenced but never imported (guaranteed
  `ReferenceError`). `Float32Array` views over `Buffer.from()` threw
  `RangeError` on unaligned offsets. `weightedFedAvg` accepted mismatched
  gradient lengths and produced `NaN`.

**Medium**
- SSRF blocklist covered one /16 of `172.16/12` and no integer, IPv6, or
  IPv4-mapped literals, nor metadata hosts. Replaced with a real validator,
  re-checked at dispatch, redirects disabled.
- Crons failed open without `CRON_SECRET` (could be triggered to send mail and
  mark models tampered). Now 503 + constant-time compare.
- `/api/notifications` was an open mail relay; recipients restricted to
  `ALERT_EMAIL` or `ALERT_EMAIL_ALLOWLIST`.
- `GET /api/status` mutated state, sent email, and fired webhooks;
  `GET /api/inference-cache` wrote an audit record per request (unbounded
  keyspace growth). Both fixed.
- `DELETE /api/schedule` matched by key **suffix**, so `?id=0` deleted an
  unrelated job.
- CSV compliance export was formula-injectable; email templates interpolated
  user data unescaped.
- Error responses no longer echo internal Redis/Shelby/Aptos SDK messages in
  production.

## Known gaps

Tracked honestly rather than papered over:

- **Explorer** — Shelbynet has no first-party explorer UI for arbitrary
  transactions, so all links use Aptos Explorer in custom-network mode against
  the Shelbynet RPC. Built in exactly one place: `explorerUrl()` in
  `lib/registry.js`, surfaced to the frontend via `GET /api/config`.
- **Rate limiting** — fixed-window, and the limiter trusts the first
  `X-Forwarded-For` entry, which is only safe behind Vercel's proxy.
- **Scheduled deployments** — `POST /api/schedule` persists jobs, but no cron
  consumes the queue yet; only `expiry-check` and `tamper-check` are registered
  in `vercel.json`.
- **Custom domains for Sites** — every site is served at `/s/<slug>`. Per-site
  subdomains and custom domains are not implemented.
- **Micropayment replay** — a BCS payload is not checked for reuse across
  intents; the on-chain `receiverWithdraw` failing is the only defence.
